# Changelog

## 1.0.0

First release.

- **Capsule HUD**: one pill-shaped, animated on-screen display. The icon appears first, the pill opens from the
  middle, then closes back the same way. It never takes focus and clicks pass through it.
- **Devices and sound**: headphones, game controllers (with battery), volume and mute, microphone mute,
  now playing with album art, USB drives, and a camera / microphone in-use privacy alert.
- **Keyboard, screen and network**: keyboard language switches, Caps Lock / Num Lock, laptop brightness,
  Wi-Fi / Ethernet / internet / VPN changes.
- **System health**: alerts when the CPU or GPU stays busy, the GPU runs hot or the CPU is slowed by heat, memory or
  disk space runs low, and for battery and charger changes (including headphones and controllers running low).
- **Auto-switching**: sound (and optionally calls) moves to headphones when they connect and back when they leave.
  Your usual microphone is kept when Bluetooth headphones try to take it over.
- **Rename devices** for the HUD and tray menu.
- **Make it yours**: click-to-place position, monitor, size, dark / light / system theme, accent colour, duration,
  with a live preview.
- **Updates**: a daily check of GitHub releases (can be turned off); installs only when you agree, after verifying the
  download's size and SHA-256.
- **Light on your PC**: event-driven watchers, Windows Efficiency mode, GPU-cached HUD, pauses while the PC is locked.
- **Experimental**: hide the built-in Windows volume / brightness pop-up.
- New settings window with Home, Sound, HUD look, What it shows, Device names and General pages; light, dark or
  same-as-Windows.
